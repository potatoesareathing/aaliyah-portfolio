SpecForge

Universities write course specifications by hand, and they drift from the official format. SpecForge reads a messy spec, plus an optional question-paper blueprint, and returns a corrected one in the official template.

  • Re-derives the CO-PO-PSO map instead of copying the old one
  • Rule-based validation report that explains every change
  • Author, reviewer and HOD approval workflow
  • Bring your own AI key (Gemini, OpenRouter or Anthropic), kept only in your browser

How this site is built

The room is a real 3D scene made with Three.js. It's rendered at a fraction of the screen's resolution, then scaled up with hard pixel edges and an ordered dither, which turns smooth 3D into pixel art. The page is plain HTML and TypeScript bundled by Vite, and the games are the original pygame code compiled to WebAssembly with pygbag.
